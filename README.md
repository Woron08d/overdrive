## Стек технологий

- **База данных:** PostgreSQL
- **Сервер:** Node.js, Express
- **Фронтенд:** HTML, CSS, JavaScript (без фреймворков)

## Как запустить

1. Установить Node.js и PostgreSQL
2. Создать базу данных:
   psql -U postgres -f overdrive.sql
3. Загрузить тестовые данные:
   psql -U postgres -d overdrive -f seed.sql
4. Вписать пароль от базы в файл db.js
5. Установить зависимости и запустить:
   npm install
   npm start
6. Открыть http://localhost:3000
